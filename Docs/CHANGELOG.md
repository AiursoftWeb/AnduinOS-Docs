## Updating AnduinOS

AnduinOS 2 uses the standard APT upgrade path:

```bash title="Update AnduinOS 2"
sudo apt update
sudo apt upgrade
```

AnduinOS 1 used a legacy upgrade command. See the [AnduinOS 1.x Release Notes](./Release-Notes/1.x.md) and the [versions table](https://www.anduinos.com/HistoryBuilds.html) for historical information.
