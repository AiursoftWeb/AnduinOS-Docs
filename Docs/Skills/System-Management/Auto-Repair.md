# Auto Repair — retired in AnduinOS 2

The legacy `do-anduinos-autorepair` tool belongs to AnduinOS 1.x and was
[retired in AnduinOS 2.0](../../Release-Notes/2.0.0.md). Do not download an old
repair script or import desktop defaults from the old ISO-builder repository
to repair an AnduinOS 2 installation.

Use the [backup and recovery guide](../../Install/Backup-And-Restore.md) for
recovery planning, or the [Disk Snapshots Manager guide](../../Applications/System/Disk-Snapshots-Manager/Disk-Snapshots-Manager.md)
when a suitable snapshot is available. APT updates are not a factory reset,
and no repair or rollback should be described as guaranteeing that data is safe.

This address remains as a retirement notice for existing bookmarks.
