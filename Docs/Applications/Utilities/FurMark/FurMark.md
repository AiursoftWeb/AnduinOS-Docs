# FurMark

FurMark is a GPU stress-testing and benchmarking utility from Geeks3D. It supports OpenGL and Vulkan and can publish benchmark scores to an online database.

## Flatpak install (Recommended)

Open **Software**, search for **FurMark**, and select the Flathub version. You can also open its [Flathub page](https://flathub.org/apps/com.geeks3d.furmark).

To install it from a terminal:

```bash
flatpak install flathub com.geeks3d.furmark
```

If Flathub is not configured, follow the [Flathub setup guide](../../Store/Flathub/Flathub.md) first.

## Launch FurMark

Search for **FurMark** in the application menu, or run:

```bash
flatpak run com.geeks3d.furmark
```

Choose a benchmark to measure GPU performance or a stress test to exercise the GPU under sustained load. Ensure adequate cooling while testing; the Flathub listing warns that insufficient cooling can damage the device.
