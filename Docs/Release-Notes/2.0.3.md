# AnduinOS 2.0.3 Release Notes

!!! warning "Under Development"

    AnduinOS 2.0.3 is still under development. Features, package relationships, and wording may change before the final release.

AnduinOS 2.0.3 improves installation flexibility and everyday system management. Highlights include a redesigned advanced-storage workflow for installing alongside Windows, centralized system settings, private voice typing, and the transition to Dracut, together with regional consistency and UEFI reliability improvements.

Live-image and installation-flow changes apply primarily to new installation media. Existing AnduinOS 2 systems receive compatible application, desktop, privacy, security, and boot-stack updates through APT, including a guarded migration to Dracut where applicable.

## New Features

* **AnduinOS Control Panel:** Added `anduinos-control-panel`, a category-based home for system, hardware, application, account, appearance, AI, compatibility, and recovery settings. It brings AnduinOS tools and selected GNOME settings into one searchable interface, can offer supported optional applications when they are not installed, and exposes individual settings through GNOME Shell search.
* **Startup and Boot Settings:** The Control Panel can change the GRUB boot-menu wait time and choose an appropriate boot display mode through a narrowly scoped privileged helper. The interface distinguishes UEFI from unsupported Legacy BIOS Secure Boot configurations and refreshes the boot menu after validated changes.
* **Private Voice Typing:** Added an optional offline voice-typing stack built around `whisper.cpp`. It provides a GTK4 settings and microphone-calibration interface, a GNOME Shell integration for starting and stopping dictation, configurable keyboard shortcuts, local speech recognition, and clear installation and session-activation guidance before use.
* **Live Transcription:** Voice Typing can display partial recognition results while speech is still being processed, provides clearer listening and processing states, and normalizes recognized Chinese text according to the selected script preference.
* **GNOME Settings Backup and Restore:** AnduinOS Appearance can export GNOME settings, layouts, and extension preferences to a readable INI file. Imports can merge selected settings with the current profile or perform a strict restore, with automatic rollback when an import fails.
* **Proxy Status Indicator:** The redesigned Proxy Switcher shows a panel status icon whenever the system proxy is active, making the current proxy state immediately visible. It also provides quick access to Off, Manual, and Automatic modes and remembers the last active mode when the proxy is toggled off and back on.
* **Redesigned Advanced Installation:** The native installer's advanced-storage workflow gives users more control over installing AnduinOS alongside Windows on the same disk. It improves manual partition planning and feedback, allows explicit choices about which partitions to preserve, delete, create, or format, and provides inline filesystem selection. This addresses the advanced-installation problem reported in [AnduinOS #425](https://github.com/Anduin2017/AnduinOS/issues/425).
* **Guarded NTFS Shrinking:** Manual partitioning can shrink an eligible, healthy, unencrypted NTFS partition to make room for AnduinOS without moving the partition's start. This is an explicit operation with strict safety checks, not automatic Windows resizing or general-purpose partition resizing. See the limitations below.
* **Flexible Storage Settings:** Added configurable Swap sizing and a dedicated automatic disk-layout settings flow. Manual layouts support Btrfs, Ext4, XFS, and F2FS where the partition role permits them; automatic and guided layouts continue to offer Btrfs or Ext4.
* **Complete Keyboard Layout Catalog:** The installer now reads the complete XKB keyboard catalog instead of presenting only a maintained subset. Layouts and variants remain searchable and can be previewed without changing the active Live-session keyboard unexpectedly. This broader catalog is intended to cover regional variants such as German (Switzerland); final validation remains tracked in [AnduinOS-2 #12](https://github.com/AiursoftWeb/AnduinOS-2/issues/12).
* **Guided Optional Application Setup:** The Control Panel provides guided installation paths for optional local AI, offline Voice Typing, Flatseal permission management, and Bottles-based Windows compatibility. Package and Flatpak operations display their progress and retain diagnostic output for failures.

### Advanced Storage: Scope and Safety

Guided coexistence uses existing unallocated space on supported UEFI/GPT disks and reuses a validated EFI System Partition without formatting it. It does not automatically shrink Windows. The manual GPT editor provides explicit partition operations, including the guarded NTFS shrink path described above.

NTFS shrinking is rejected for BitLocker-encrypted, mounted, hibernated, Fast-Startup-affected, dirty, or inconsistent volumes. Before writing, the installer repeats its target-specific checks and resize dry run. It shrinks the filesystem before reducing the partition boundary and verifies the resulting layout before creating new partitions. It does not move partitions or resize Ext4, Btrfs, XFS, or F2FS filesystems.

!!! warning "Development status and data protection"

    These storage changes are implemented in the development installer, but real Windows coexistence and interrupted-resize qualification remain release requirements. Do not treat their inclusion in these development notes as completed release qualification. Back up important data before changing partitions; resizing is not a substitute for a backup.

## Behavior Changes

* **Pure Dracut Boot Stack:** AnduinOS installation media and installed systems now use Dracut instead of the former Casper and initramfs-tools stack. New Live images are composed directly for Dracut, while existing installations use a one-shot migration package that stages the new initramfs, retains a recovery path until a successful boot is confirmed, and removes obsolete boot-stack packages only after the transition is safe.
* **Atomic Dracut Migration:** The Dracut switch waits until all required packages are available from the configured repository, survives interruption or power loss, verifies the generated initramfs at the appropriate kernel-package stage, and retries safely when publication or configuration is incomplete. Package scripts avoid refreshing GRUB inside image-building chroots.
* **Independent Live and Installed Regions:** Language, timezone, and keyboard selections made in the GRUB region menu configure the Live session. The installer can independently select the language, timezone, keyboard, and input methods for the installed system, allowing users to test in one region without forcing that choice onto the final installation. Follow-up validation of installed input-source persistence remains tracked in [AnduinOS-2 #13](https://github.com/AiursoftWeb/AnduinOS-2/issues/13).
* **Earlier Live Keyboard Configuration:** The selected Live keyboard layout is applied before GDM starts and does not require PolicyKit authorization. The login screen, desktop session, terminal, and installer therefore begin with the same validated keyboard choice.
* **Centralized System Tools:** AnduinOS-specific applets and selected system destinations now open through the Control Panel. ArcMenu and desktop shortcuts use these centralized routes, while the Control Panel keeps direct access to the underlying Appearance, Driver Center, Firewall, Swap, YubiKey, snapshots, networking, account, printer, scanner, and software tools.
* **Explicit Weather Location Consent:** The desktop no longer performs an implicit SimpleWeather location lookup. AnduinOS Appearance explains the request and asks for consent before using the network to determine a location for weather configuration.
* **Explicit Voice Model Consent:** Enabling offline Voice Typing shows the approximate model download size and requires an explicit installation action. Speech recognition remains local after the model is installed.
* **Safer Automatic Updates:** Unattended upgrades are limited to trusted Ubuntu and AnduinOS origins configured for the system. Third-party repositories are not silently included in unattended package installation.
* **Responsive Settings Windows:** AnduinOS GTK applications use more consistent scrolling, default window sizes, and narrow-window layouts, making settings pages easier to use on small displays.
* **Taskbar Layout Naming:** The numeric `11` taskbar-layout label is now presented as **Centered** across the interface and translations.
* **Installer Naming:** The native installer is now presented as **AnduinOS Installer** without the former **Beta** qualifier.

### Packaging and Release Engineering

The following changes are mostly invisible during everyday use, but make upgrades, installation media, and release qualification safer:

* The Live-image builder now owns one Dracut-specific composition path instead of maintaining parallel Casper patching and initramfs update paths.
* Dracut migration packages use staged publication and dependency checks so a partially synchronized repository cannot begin an incomplete boot-stack transition.
* Release acceptance tests perform a real UEFI boot regression check, validate the transition from firmware to the graphical session, and retain serial diagnostics when a guest fails to reach the expected state.
* Regional acceptance tests verify that Live-session choices and installed-system choices remain independent, including language, timezone, keyboard layout, and input methods.
* QEMU test cleanup reclaims orphaned virtual disks after interrupted runs, and long-running serial and GDM checks tolerate delayed or incomplete guest output without hiding genuine failures.
* Package tests more deterministically validate Secure Boot state, Driver Center behavior, localization coverage, Btrfs translations, GNOME Shell extensions, and the exact package revision included in an image.

## Bug Fixes

* **UEFI Boot Registration:** Fixed whole-disk UEFI installations that could repeatedly show **Reset System** because firmware returned to shim's fallback registrar instead of starting the installed AnduinOS entry. In UEFI mode, the installer now keeps the normal installed-system loader in `EFI/AnduinOS`, avoids deploying the fallback registrar as the primary boot path, creates an explicit firmware entry bound to the selected EFI System Partition and loader, places that entry first in `BootOrder`, and verifies the resulting firmware state. It stops before destructive whole-disk work when EFI variables are unavailable instead of completing an installation that depends on first-boot registration. Fixes [AnduinOS #422](https://github.com/Anduin2017/AnduinOS/issues/422). Multi-disk EFI System Partition selection remains separately tracked in [AnduinOS-2 #6](https://github.com/AiursoftWeb/AnduinOS-2/issues/6).
* **Secure Boot Verification:** Fixed Secure Boot checks that could reject a valid vendor-only trust configuration. Legacy BIOS installations are now reported as not supporting Secure Boot instead of being presented as an enrollable configuration.
* **Dracut Rollback Integrity:** Fixed migration rollback confirmation so the old boot path is not removed before the first successful Dracut boot has been verified.
* **Read-Only Initrd Recovery:** Fixed recovery staging when the current initrd or its source location is read-only, and allowed obsolete cryptsetup initramfs integration to be removed during a completed migration.
* **Btrfs Scrub Reporting:** Fixed Disk Snapshots Manager scrub progress, privileged recovery status, completion results, and stale runtime-state handling.
* **Btrfs Snapshot Tool Retention:** Fixed Disk Snapshots Manager becoming eligible for automatic removal after installation. Btrfs installations now explicitly retain it, including fully offline installations, while it remains optional on non-Btrfs systems.
* **Live Keyboard Startup:** Fixed the Live keyboard layout being applied too late for GDM or requiring an unavailable desktop authorization path.
* **Seamless Taskbar Startup:** Dash to Panel is now prioritized ahead of other panel extensions such as ArcMenu during GNOME Shell startup. The stock GNOME top panel remains hidden while the taskbar initializes, preventing the top panel and misplaced extension elements from briefly flashing after login.
* **Virtual Machine Shutdown:** Limited the SPICE guest agent shutdown wait to 15 seconds, preventing rare 90-second delays during shutdown or restart in virtual machines.
* **Theme Shutdown Race:** Fixed a race during user-theme teardown that could leave GNOME Shell theme state inconsistent during logout or package changes.
* **Login Message Permissions:** Restored executable permissions for the AnduinOS MOTD script so branded login information appears consistently.
* **Separated Layout Spelling:** Corrected the user-facing spelling of the **Separated** taskbar layout. Fixes [AnduinOS #427](https://github.com/Anduin2017/AnduinOS/issues/427).
* **Localization:** Improved translation coverage and corrected Italian and other localized strings across AnduinOS applications. Additional German OOBE corrections remain tracked in [AnduinOS-Packages #9](https://github.com/AiursoftWeb/AnduinOS-Packages/issues/9).
