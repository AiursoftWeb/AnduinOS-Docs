# AnduinOS 2.0.7 Release Notes

AnduinOS 2.0.7 continues to use Ubuntu 26.04 LTS (Resolute) and GNOME 50. These release notes are a draft.

## New Features

* **Parental Controls** — Open **Parental Controls** from the Start menu to manage a standard user account. You can restrict specific apps in the Start menu and set a daily screen time limit. The desktop locks when the account reaches its limit.
* **Croatian Language Support** — Added full Croatian (Hrvatski) support across the boot menu, installer, and all first-party apps, expanding the officially supported languages to 29. Special thanks to community contributor **Viktor** ([drdrummie](https://github.com/drdrummie/AOS-cro-translations)) for contributing the translations!
