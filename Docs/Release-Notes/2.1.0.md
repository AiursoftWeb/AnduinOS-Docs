# AnduinOS 2.1.0 Release Notes

AnduinOS 2.1.0 brings Ubuntu 26.10 (Stonking) and GNOME 51, along with the improvements in 2.0.6. These release notes are a draft.

Install 2.1.0 using new installation media. Existing AnduinOS 2.0 users should wait for a supported upgrade procedure before moving to 2.1.0.

## New Features

* **Ubuntu 26.10 and GNOME 51:** Updated the system base to Ubuntu 26.10, Linux 7.3, and GNOME 51, with matching login-screen styling and desktop extensions. Third-party GNOME 50 extensions may need updates.

* **Impression USB Image Writer:** Impression replaces Startup Disk Creator for writing installation images to USB drives.

* **Mainland China Software Sources:** Simplified Chinese users can choose mainland China servers for AnduinOS packages and Flathub during installation or first-run setup. Global servers remain the default. A failed connection check keeps the previous server settings. Ubuntu mirrors have their own selector.

* **Application Icons:** Choose Fluent or Adwaita application icons in **AnduinOS Appearance → Application Icons**. Your choice is saved across accent-color changes and later sessions. See [the icon-theme request (AnduinOS-2 #41)](https://github.com/AiursoftWeb/AnduinOS-2/issues/41).

* **Parakeet Voice Typing:** Voice Typing adds the optional **Parakeet TDT 0.6B v3 INT8** model for local speech recognition in 25 European languages. It requires a download of about 631 MB and about 1.5 GiB of working memory. After downloading, select **Use** to switch to it. Whisper Base remains the default. See [the dictation feedback and comparison in discussion #480](https://github.com/Anduin2017/AnduinOS/discussions/480#discussioncomment-19568463).

* **Window Layout Menu:** Enable **Show Top Window Layout Menu** in Appearance to see layout choices when dragging a window to the top of the screen. It is off by default. See [Shortcuts and Appearance](../Install/Shortcuts-and-Appearance.md).

* **First-Run Feedback:** You can leave an optional star rating and a short suggestion at the end of Welcome Center's setup.

* **Bash Command Suggestions:** Command suggestions now work after `sudo` and shell operators. For example, after `apt update && sudo `, Bash can suggest `apt upgrade`, using flags from your command history.

## Behavior Changes

* **Desktop Icons:** New 2.1 installations use the GTK 4 version of Desktop Icons NG. AnduinOS 2.0 keeps GTK 3, and updates preserve the version already installed. See [the multi-monitor discussion #430](https://github.com/Anduin2017/AnduinOS/discussions/430).

* **File Preview:** Sushi's Space-key file preview is no longer preinstalled.

* **Restart After Snapshot Restore:** Restoring System, Home, or factory settings now automatically restarts the computer before loading the restored system. This fixes kernel and driver mismatches when restoring across kernel updates. The temporary boot entry is named **Start snapshot rollback (one-time)**. Some older snapshots require recovery through Live media. See [Disk Snapshots Manager](../Applications/System/Disk-Snapshots-Manager/Disk-Snapshots-Manager.md).

* **Printer Settings:** Driver Center shows configured printers and opens GNOME's printer settings to manage them. The printer list refreshes when you return. See [printing and scanning](../Applications/System/Driver-Center/Driver-Center.md#printing-and-scanning).

* **Graphics Driver Status:** Driver Center now recognizes Intel graphics using the built-in driver as ready to use.

## Bug Fixes

* **Application Icons:** Fixed the selected application icons reverting to Adwaita after locking the screen or reloading desktop extensions, including during updates.

* **Login-Screen Wallpaper:** Package updates now keep your selected login-screen wallpaper, even if the original image file has been deleted.

* **Dark Theme After Locking:** Fixed screen locking resetting the GTK theme and leaving applications with light window decorations in dark mode. See [the Firefox and Thunderbird report (AnduinOS-2 #37)](https://github.com/AiursoftWeb/AnduinOS-2/issues/37).

* **On-Screen Keyboard:** Fixed the Start menu covering the on-screen keyboard while typing in its search box. See [the original touchscreen report on Reddit](https://www.reddit.com/r/AnduinOS/comments/1xomzdw/touchscreen_keyboard_hiding/) and the [ArcMenu fix](https://gitlab.com/arcmenu/ArcMenu/-/merge_requests/287).

* **Firmware Updates With Secure Boot:** Fixed firmware updates failing to find the signed bootloader on AnduinOS. See [the Dell firmware-update report (AnduinOS-2 #39)](https://github.com/AiursoftWeb/AnduinOS-2/issues/39).

* **Bootloader Setup:** The installer now checks and prepares the bootloader after installing updates, fixing an out-of-date bootloader status on the first startup.

* **Installer Downloads:** If an Ubuntu mirror fails to download packages, the installer can try another mirror. This now covers language packs, input methods, and multimedia packages. Each replacement mirror must pass signature checks.

* **Automatic Snapshots:** Fixed the automatic snapshot service reporting a failure when startup and scheduled tasks run within seconds of each other. Duplicate requests are now skipped normally.

* **Home Restore:** Fixed restoring Home repeatedly booting into the restore tool. The computer now returns to normal startup after the restore finishes.

* **Closing Live Rescue:** Rescue Center now finishes closing its repair terminal and unmounting disks before installation can proceed. If a repair session is still open, the installer tells you to close it and try again.

* **Btrfs Recovery:** Fixed Live recovery rejecting systems with empty storage subvolumes created by systemd. Storage subvolumes containing data remain protected.

* **Installation Media Verification:** Fixed installation-media verification failing because a required file-path tool lacked the necessary options.

* **Desktop-Icon Window Focus:** Fixed a window-focus error caused by the GTK 3 desktop-icon extension activating a window before it was ready.

* **Firewall Diagnostics:** The Firewall app now detects other firewall rules that can keep blocking traffic after UFW is turned off. It also reports incomplete checks and missing replies more clearly. See [the Samba investigation (AnduinOS-2 #40)](https://github.com/AiursoftWeb/AnduinOS-2/issues/40).

* **Driver Center Layout:** Fixed navigation and driver details overflowing in narrow windows.

* **Driver Builds During Updates:** Fixed driver builds failing when DKMS was being updated. Driver cleanup errors are now reported.

* **Xbox Controller Driver Updates:** Improved xpadneo updates so the driver rebuilds for installed kernels and removes obsolete driver registrations. Existing stale registrations may need manual cleanup. See [the kernel-update report (AnduinOS-2 #38)](https://github.com/AiursoftWeb/AnduinOS-2/issues/38).

* **Input-Source Preferences:** Fixed Japanese Mozc reappearing after login when it had been removed from the input-source list.

* **Taskbar Auto-Hide:** Fixed the hidden taskbar sometimes failing to reappear when moving the pointer to the screen edge.

* **Start-Menu Translations:** Fixed power-action labels in the Start menu appearing in the wrong language.

* **Flatpak on First Login:** Fixed missing Flatpak service-directory errors during the first login.

* **Windows App Recommendations:** Corrected the Office alternatives message so it no longer says LibreOffice is preinstalled.

* **System Information:** Updated the AnduinOS logo and privacy-policy link shown in GNOME's system information. Welcome Center also clarifies the system's privacy commitments.

* **French Translations:** Improved French installation and repair messages, including replacing **Sortie avancée** with **Détails techniques**. See [the translation feedback in discussion #480](https://github.com/Anduin2017/AnduinOS/discussions/480#discussioncomment-19557733).

* **Parental-Control Services:** Installed the missing service dependencies that caused parental-control errors in the system log.

* **Login-Screen Layout:** Updated the login theme for GNOME 51, fixing the layout of password and authentication controls.

* **Login-Screen Crash:** Included the Ubuntu GDM update that fixes the login-screen crash seen in early Stonking images. See [the official package changelog](https://changelogs.ubuntu.com/changelogs/pool/main/g/gdm3/gdm3_51.0-0ubuntu1.1/changelog).

* **Startup Logo in Virtual Machines:** Improved display setup so the startup logo appears correctly in virtual machines using VirtIO graphics.

* **Input-Method Installation:** Fixed installation checks rejecting Rime because its files moved to a different directory in Stonking.

## Documentation and Packaging

* **License Notices:** Updated license notices for bundled firmware, themes, extensions, drivers, and system tools. Large notice files are compressed to save space.

* **Source-Code Links:** Updated package information and documentation to link to the public source code on GitHub.

## Known Issues

* **Chinese Input:** An upstream IBus issue can produce GNOME Shell error messages after Chinese input.
* **Location Service:** An upstream GLib deadlock can prevent GeoClue from starting, affecting applications that request your location.
* **Parental Controls:** An upstream Malcontent timing issue can produce errors in the system log, including when screen-time limits are disabled.
* **Disk Service Startup:** An upstream UDisks2 initialization race can produce a startup warning. It was reproduced using diagnostic timing controls.
