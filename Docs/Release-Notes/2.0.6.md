# AnduinOS 2.0.6 Release Notes

AnduinOS 2.0.6 introduces an independent recovery environment for restoring a system that can no longer boot. These release notes are a draft.

## New Features

* **Independent Recovery Environment:** Select **AnduinOS Recovery Environment** from the GRUB boot menu to browse system snapshots and restore a recovery point without a Live USB or network connection, even when the installed system's kernel, initramfs, or startup programs are damaged. The graphical browser includes a **Last successful boot** marker to help choose a recovery point; the marker is guidance, not a guarantee that the snapshot will boot. Recovery asks for confirmation before replacing system files and applications, preserves personal files, and offers to restart when complete. A text menu remains available if the graphical interface cannot start.

This feature is included in new AMD64 and ARM64 installations using the installer's **Erase disk** option with a supported, unencrypted Btrfs layout. Ordinary upgrades do not add a recovery partition to existing installations. Ext4 and reused-partition installations do not receive this feature. See the [recovery design and maintenance guide](../Skills/System-Management/Recovery-Environment.md).

!!! note "Secure Boot compatibility"

    Recovery has been validated with Secure Boot disabled. Startup with Secure Boot enabled has not yet been verified, and boot-time authentication of the recovery initramfs is not yet implemented.
