# AnduinOS 2.0.6 Release Notes

AnduinOS 2.0.6 adds an independent recovery environment and recovery preparation in Driver Center. Compared with 2.0.5, it also improves Bash suggestions, input-source preferences, taskbar behavior, and driver upgrades while retaining Ubuntu 26.04 LTS (Resolute) and GNOME 50. These release notes are a draft.

Live-media and installer changes require newly built 2.0.6 or newer installation media. Existing AnduinOS 2.0 installations can receive applicable package updates through APT; updating an installed system does not rewrite an older USB installer or migrate it to Ubuntu 26.10.

!!! warning "Recovery and Secure Boot"

    The recovery environment does not yet authenticate its initramfs at boot. Normal-system Secure Boot support does not establish a fully authenticated recovery chain. Keep trusted installation media available.

## New Features

* **Independent Recovery Environment:** A new **AnduinOS Recovery Environment** boot-menu entry starts a separate kernel and recovery interface. It can restore supported Btrfs system snapshots without a Live USB or network connection while preserving personal files. The graphical browser identifies the **Last successful boot** checkpoint and offers **Snapshot Current State** before rollback when the required boot files and metadata remain readable. System Information and expandable error details help diagnose failures; a text interface is available when graphical startup is unavailable. The recovery interface is currently English.

* **Recovery Preparation in Driver Center:** Driver Center checks recovery deployment and guides installation and boot-entry repair. On eligible existing systems, it can create a 256 MiB recovery partition from an ordinary GPT swap partition of at least 512 MiB on the system disk. Preparation checks the layout and requires explicit confirmation. Unsupported layouts do not offer this action.

* **Bash Command Suggestions:** Command prediction handles empty commands after `sudo` and shell operators. After `apt update && sudo `, it can suggest `apt upgrade` and reuse preferred flags from matching history. Accepting a suggestion inserts text; it does not execute it.

## Behavior Changes

* **Desktop Icons:** AnduinOS 2.0 (Resolute) keeps the GTK 3 edition of Desktop Icons NG as its default. The GTK 4 default planned for [AnduinOS 2.1](2.1.0.md) does not switch existing 2.0 installations; normal package upgrades preserve the edition already installed.

* **Recovery Storage:** New supported, unencrypted Btrfs whole-disk installations create a dedicated recovery volume, hidden from ordinary desktop file browsing. Package updates do not repartition existing systems; recovery preparation is a separate Driver Center action. Ext4 roots and encrypted layouts do not support this Btrfs recovery workflow. Removing the recovery package removes its boot-menu entry but retains recovery data.

* **Driver Center Status:** Graphics-driver summaries are clearer, and recovery deployment has its own status and guided repair actions.

* **Privacy Information:** System identity now links to the AnduinOS privacy statement rather than Ubuntu's privacy page.

## Bug Fixes

* **Input-Source Preferences:** Signing in no longer adds Japanese Mozc back after the user removes it from the input-source list.
* **Taskbar Auto-Hide:** Fixed pointer reveal after a rejected auto-hide activation, allowing the panel to appear again when the pointer reaches the screen edge.
* **Start-Menu Translations:** Corrected initialization of translated power-action labels.
* **DKMS During Upgrades:** Driver build commands remain available throughout package replacement, avoiding failures caused by a temporarily missing DKMS frontend.
* **Xbox Drivers with Multiple Kernels:** The optional Xbox driver rebuilds for each installed kernel with the required headers, rather than assuming that only one kernel needs a module.

## Known Issues

* **Upstream Desktop Services:** IBus object-reference diagnostics and incomplete Malcontent service packaging remain under investigation; this release does not claim to fix them.
