# AnduinOS 2.0.6 Release Notes

!!! note "Draft — upcoming maintenance release"

    These notes describe changes since 2.0.5. The final package set and installation media are still being qualified; this is not a release announcement.

AnduinOS 2.0.6 adds an independent recovery environment and a guided way to prepare it on eligible existing systems. It also improves input-source preferences, Bash suggestions, taskbar behavior, and driver upgrades while retaining the Ubuntu 26.04 LTS base.

## Independent recovery environment

A new **AnduinOS Recovery Environment** entry can start a separate kernel and recovery interface when the installed desktop cannot boot. It allows supported Btrfs system snapshots to be restored without a Live USB or network connection while preserving personal files.

The graphical browser lists recovery points and marks the checkpoint associated with the **Last successful boot**. That marker helps selection but does not guarantee that a snapshot will boot. **Snapshot Current State** can preserve the installed system before rollback when its required boot files and metadata remain readable. The interface warns when no current-state snapshot has been created. A System Information view supplies read-only diagnostic details, and failures have a separate details page. A text interface is available when graphical startup is unavailable; the recovery interface is currently English.

New supported, unencrypted Btrfs whole-disk installations create a dedicated recovery volume. Ordinary package upgrades do not repartition existing systems. Driver Center can inspect and repair recovery deployment. Its preparation action can create a 256 MiB recovery partition from an eligible ordinary GPT swap partition of at least 512 MiB on the system disk, then guide installation and boot-entry repair. It checks the disk layout and requires explicit confirmation; it does not silently repartition the machine during an update. Unsupported layouts do not offer this action. Ext4 roots and encrypted layouts do not gain this Btrfs recovery capability.

The recovery volume is hidden from ordinary desktop file browsing. Removing the recovery package removes its boot-menu entry but retains recovery data. Boot-success recording is restored when the package is reinstalled.

!!! warning "Recovery qualification is separate from normal Secure Boot"

    Normal-system Secure Boot support does not establish recovery-environment support. The recovery package remains under qualification, and boot-time authentication of its initramfs is not implemented. Do not rely on it as a fully authenticated recovery chain. Keep trusted installation media available.

## Desktop and driver improvements

* **Input-source preferences:** Signing in no longer adds Japanese Mozc back after it has been removed from the input-source list. The installer and the user remain responsible for choosing input sources.
* **Command suggestions:** Bash prediction now handles an empty command after `sudo` and shell operators. After `apt update && sudo `, it can suggest `apt upgrade` and reuse preferred flags from matching history. Accepting a suggestion inserts text; it does not execute it.
* **Taskbar auto-hide:** Fixed pointer reveal after a rejected auto-hide activation, allowing the panel to appear again when the pointer reaches the screen edge.
* **Start-menu translations:** Corrected initialization of translated power-action labels.
* **DKMS during upgrades:** Driver build commands remain available throughout package replacement, avoiding failures caused by a temporarily missing DKMS frontend.
* **Xbox drivers with multiple kernels:** The optional Xbox driver rebuilds for each installed kernel with the required headers, rather than assuming that only one kernel needs a module. This package remains optional.
* **Driver Center status:** Graphics-driver summaries are clearer, and recovery status now has its own inspection and guided repair workflow.
* **Privacy information:** System identity links to the AnduinOS privacy statement rather than Ubuntu's privacy page.

## Updating from 2.0.5

AnduinOS 2.0.6 stays on Ubuntu 26.04 LTS (Resolute) and GNOME 50. Once the release is available, existing 2.0.5 installations can receive applicable updates through their normal APT source without reinstalling or switching Ubuntu suites.

An ordinary update does not create a recovery partition, replace a working bootloader, or require new MOK enrollment solely because the AnduinOS version changed. Recovery setup on an existing eligible system is an explicit Driver Center operation. New-installation layout changes require new installation media.

These notes describe the upcoming maintenance release, not confirmation that every current test-source package or image has completed release qualification. Ubuntu IBus and Malcontent issues remain under investigation; they are not claimed as fixes in this release. The recorded upstream status must be checked again before publication.
