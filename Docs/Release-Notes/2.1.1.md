# AnduinOS 2.1.1 Release Notes

AnduinOS 2.1.1 continues to use Ubuntu 26.10 (Stonking) and GNOME 51. These release notes are a draft.

## New Features

* **Desktop Resource Protection** — Added **System → Resource Allocation Settings** in Control Panel. Prioritize desktop resources, adjust memory protection and foreground app priority, and inspect application progress. Settings remain in effect after restarting. Heavy terminal jobs can use `aos-bg` to run in a separate background group. See [Desktop Resource Protection](../Skills/System-Management/Desktop-Resource-Protection.md).

* **Parental Controls** — Open **Parental Controls** from the Start menu to manage a standard user account. You can restrict specific apps in the Start menu and set a daily screen time limit. The desktop locks when the account reaches its limit.
* **Croatian Language Support** — Added full Croatian (Hrvatski) support across the boot menu, installer, and all first-party apps, expanding the officially supported languages to 29. Special thanks to community contributor **Viktor** ([drdrummie](https://github.com/drdrummie/AOS-cro-translations)) for contributing the translations!
