# AnduinOS 2.1.1 Release Notes

AnduinOS 2.1.1 continues to use Ubuntu 26.10 (Stonking) and GNOME 51. These release notes are a draft.

## New Features

* **Parental Controls** — Open **Parental Controls** from the Start menu to manage a standard user account. You can restrict specific apps in the Start menu and set a daily screen time limit. The desktop locks when the account reaches its limit.
* **Croatian Language Support** — Added full Croatian (`hr_HR.UTF-8`) localization across the operating system, expanding the roster of officially supported languages to 29. Select **Hrvatski** directly from the GRUB boot menu to start a localized Live session with Croatian regional settings and keyboard layout, or choose it in the installer to configure the installed system. Translation catalogs are included across first-party desktop applications, including Appearance, Control Panel, Driver Center, Firewall, Offline Updates, Virtual Memory, Welcome Center, and system recovery utilities. Special thanks to community contributor **Viktor** ([drdrummie](https://github.com/drdrummie/AOS-cro-translations)) for preparing the foundational Croatian translations!
